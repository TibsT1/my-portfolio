Tibs Diagnostic Toolkit

A lightweight cross-platform Python CLI for first-line IT troubleshooting. It is designed to collect useful checks quickly, save timestamped reports, and help separate basic connectivity issues from deeper problems that need further investigation.

What it checks

  • Direct internet reachability without relying only on DNS
  • DNS resolution
  • Local IPv4 and default gateway detection where available
  • Latency, packet loss, system, CPU, RAM and storage information
  • Website and server reachability for common port patterns

What it demonstrates

  • Python standard library usage
  • Cross-platform checks for Windows, Linux and Android Termux
  • Report generation and file handling
  • Defensive handling of missing commands and restricted APIs
  • Testing and hardening through regression tests

Self-hosting / dissertation project

Nextcloud self-hosted server

Built a private cloud storage setup using Nextcloud and Docker on personal hardware. The project helped me understand container deployment, storage planning, user access, backup thinking, local network configuration and remote access options.

Tools and concepts

  • Docker and containerised services
  • Nextcloud for private cloud storage
  • Tailscale for private remote access
  • Port forwarding as a comparison point for public exposure

What I learned

  • How self-hosted services are configured and maintained
  • Why remote access choices affect security
  • How documentation matters when rebuilding or troubleshooting
  • How home infrastructure can support a real academic project
