Tibs Diagnostic Toolkit

A cross-platform Python command-line tool for first-line IT troubleshooting. It collects common checks into timestamped reports so issues can be recorded clearly instead of guessed from memory.

Checks included

  • Internet reachability
  • DNS resolution
  • Default gateway and IPv4 details where available
  • Latency and packet-loss checks
  • System, CPU, memory and storage information
  • Website and server reachability checks

What it demonstrates

  • Python scripting and file handling
  • Cross-platform defensive checks
  • Report generation
  • Testing and regression checking
  • Practical IT support thinking
