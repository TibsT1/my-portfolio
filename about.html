I’m a practical computer person first.

I have always been interested in computers as whole systems, not just one part of them. I like the hardware, the operating system, the network, the software, the web side, and the security decisions that sit around all of it.

My degree gave me a proper academic base, but most of my confidence comes from building things myself and having to fix them when they behave badly.

My background

I graduated from Buckinghamshire New University with a BSc in Cyber Security, achieving Upper Second-Class Honours with 69% overall. My studies covered network systems, data management, databases, malware, online risks, and security threats.

Before university, I studied T-Level Digital Production, Design and Development, Games Design Level 2, IT, and Computer Science. Those courses gave me a base in Python, C#, SQL, software design, web development, game concepts, and problem solving.

Outside formal education, I built a desktop PC from individual parts, hosted cloud and media services from home, created websites, and built Python tools that solve real technical problems.

How I learn

I learn best by building something real, testing it, breaking it safely, documenting what happened, and improving it.

What I enjoy

I enjoy troubleshooting, self-hosting, practical security, clean web layouts, hardware upgrades, and anything that helps me understand computers better.

Personal detail

I like cats, gaming, home servers, and projects that start as “this should be possible” and slowly become working tools.

I like support work because it is grounded.

There is a user, a problem, a system, and a result. I like that direct connection between technical work and practical help.

I like security because details matter.

Access, data, exposure, updates, passwords, ports, and permissions all affect whether a system is sensible or risky.

I like web work because the result is visible.

A website quickly shows whether the structure, spacing, copy, links, and mobile layout actually make sense.
